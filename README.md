# 哆啦A梦 · 数据库桌宠

SillyTavern / TauriTavern 的独立 UI 扩展。它把「龙血玄黄·数据库」自带的桌宠换成哆啦A梦：动作、互动、贴边探头和任务气泡与原版保持一致，并加了一些可以单独开关的小功能。

当前版本：**v1.1.0**

本扩展在 [绘梨衣 · 数据库桌宠](https://github.com/dzsks/xiaohuizhuochong) 的代码结构上修改而来（数据库只读观察、位置保存、口袋笔记、小故事、设置面板），互动规则按数据库原版 `DeskPet.vue` 对齐。

## 安装

1. 把本文件夹里的**所有文件**放到一个公开 GitHub 仓库的**根目录**（根目录里直接就是 `manifest.json`、`index.js`、`style.css`，不要多套一层文件夹）。
2. 酒馆 → 扩展程序 → 安装扩展程序 → 粘贴仓库地址，例如 `https://github.com/你的用户名/doraemon-pet`。
   - TauriTavern 只接受匿名的 `http(s)` Git 地址，不接受 SSH、带账号密码的地址或 `…/tree/main` 这种网页地址。
3. 刷新页面，在扩展列表确认 **哆啦A梦 · 数据库桌宠** 的版本是 `1.1.0`。
4. 如果装过「绘梨衣 · 数据库桌宠」，请把它停用，两个桌宠同时开会重叠。
5. 保持「龙血玄黄·数据库」启用，并在数据库设置里**打开它自带的桌宠**。哆啦A梦会自动把原桌宠藏起来；冷笑话、任务进度和停止按钮都由数据库本身提供，关掉原桌宠会让这些信息不完整。

## 新增的小功能（都能在扩展设置里单独开关）

- **竹蜻蜓飞行**：空闲时戴上竹蜻蜓飞到屏幕另一处（默认关闭，口袋笔记里可手动触发）。
- **四次元口袋**：翻一翻口袋，随机掏出任意门、竹蜻蜓、缩小灯或记忆面包。
- **任意门**：打开门，消失后从屏幕另一边出来。
- **喂铜锣烧**：口袋笔记里投喂，会记录今天和一共吃了多少个。
- **老鼠彩蛋**：偶尔有老鼠跑过，把他吓得手舞足蹈。
- **任务表情**：数据库开始任务时吓一跳，完成时欢呼，出错时冒冷汗。
- **互动台词**：戳、摸、甩晕时会说话。
- **深夜犯困**：23 点到 6 点更容易睡着。
- **小故事**：10 篇原创小故事，每 30 秒自动换一篇。
- 大小可调（56–140 像素），可重置位置。

## 口袋笔记

电脑右键哆啦A梦，或手机长按约 1.4 秒打开。里面有：打开数据库本体、连接状态、当前任务和停止按钮、最近的通知、铜锣烧记录、互动按钮。聚焦哆啦A梦后：Enter / 空格互动，Shift + Enter 打开笔记，方向键微调位置，Home 重置位置。

## 修复与改进（相对绘梨衣版和数据库原版）

- **TauriTavern 手机端位置偏移**：TT 会把贴在 `top:0` 的固定浮层当作“顶部窗口”并强制下移一个状态栏高度，导致桌宠、拖动和气泡位置对不上。现在所有浮层都显式声明为自由窗口（`data-tt-mobile-surface="free-window"`），TT 不再改写它们。
- **TT 安卓键盘遮挡**：TT 安卓弹出键盘时网页不会缩放，只通过 `--tt-ime-bottom` 告知键盘高度。现在会读取这个值并跟踪输入框位置，桌宠和气泡不会被键盘挡住。
- **刘海 / 状态栏**：读取 TT 的 `--tt-inset-*` 或浏览器 `env(safe-area-inset-*)`，不会钻进状态栏或刘海下面。
- **通知按钮丢失**：绘梨衣版不显示数据库通知上的按钮（如“重试”）和冷笑话；现在原样显示。
- **停止按钮绕过数据库**：绘梨衣版直接调用任务的停止函数，跳过了数据库自己的“停止中”状态和失败提示；现在通过数据库原本的气泡事件执行，和点原按钮完全一样。
- **气泡只出现 4.5 秒**：现在跟随数据库轮播的节奏显示和切换。
- **图片加载失败**：所有图片都内嵌在 `sprites.js` 里，不需要额外请求图片文件，不会出现加载失败或换图闪烁。
- **甩晕误触发**：原版慢慢拖动时细小抖动也会被算作“甩动”；现在每次甩动至少要 14 像素才计数。
- **iOS 长按弹出系统菜单**：已禁用长按时的系统选中 / 菜单。
- **故事在任务刚结束时立刻弹出**：现在被打断后至少隔 1 分钟再自动讲。
- 不再依赖 `minimum_client_version`，避免 TT 版本号与 SillyTavern 不同导致不加载。

## 说明

- 本扩展只读取数据库界面已经显示的内容，不读写数据库数据；只有你点击气泡或笔记里的按钮时，才会调用数据库自己的对应操作。
- 设置保存在酒馆的 `extensionSettings["doraemon-database-pet"]`。
- 如果数据库未来改动 `DeskPetLayer`、`DeskPet` 或 `NoticeBubble` 的结构，笔记里会提示“当前数据库界面版本暂不兼容”，并保留数据库原桌宠。
- 形象取自《哆啦A梦：伴我同行》系列剧照（站立全身图 + 四张剧照里的表情），角色和画面版权归藤子·F·不二雄、东宝等权利人所有，本扩展仅供个人非商业使用。
